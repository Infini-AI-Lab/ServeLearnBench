ServeLearnBench

How well can agents self-improve from serving experience?

%%PEOPLE%%
%%BUTTONS%%

Deployed agents work under policies, constraints and preferences that are partly undisclosed and change over time. In ServeLearnBench an agent serves a stream of tasks whose hidden policy shifts between windows. After each task it sees only a score, and held-out tests at the end of every window measure what it actually learned.

What the evaluation shows

%%FINDINGS%%
Benchmark

Three domains, three tiers, one protocol

Each scenario is an evolving-environment streaming dataset: a chronological task stream split into windows, each governed by a latent environment state that may change at the next boundary. Serving and test tasks of a window cover the same policy with disjoint instances.

%%DOMAINS%%
%%TIERROWS%%
ScenarioLatent structureWindowsServingTest

Difficulty tiers

L1 · acquisition
Previously unseen states; mostly single-policy requests; Pitch profiles never repeat.
L2 · revision and composition
Earlier states are revised; multi-policy Retail requests, ranked or batched Banking decisions, recurring Pitch profiles.
L3 · non-monotonic evolution
Reversals, removals and re-entry of earlier states on top of L2's composition.

What the learner sees

  • Every task: the task, prefixed with its stream position (Current timestamp: t), and the domain documents, which may be incomplete or out of date.
  • After a serving task: its own trajectory and one line, Score: n/100.
  • Never: the hidden policy, the correct answer, the task's category, window boundaries, or any explanation. Test tasks return nothing.
  • Budget: one attempt per task, 50 tool calls, 100 turns.

How it is scored

  • Hidden-Dependent tasks need the hidden policy; Fully Specified tasks can be solved from visible information. A good learner raises the first without losing the second.
  • Retail and Banking are graded by rule (database state or decision and reason code); Pitch by an LLM-judged rubric.
  • A setting score is the mean reward × 100 over a scenario's test tasks of one category; averages weight every setting equally.

Get started

Evaluate an agent

Any OpenAI-compatible endpoint with native tool calling works. Blind, Oracle and RAG ship with the code; a new method implements two hooks, context() and update().

# install and check the nine scenarios
git clone https://github.com/haizhongzheng/ServeLearnBench.git
cd ServeLearnBench && pip install -e .
slb verify

# run a method, then score
export SLB_API_KEY=...
slb run --scenario banking_l1 --method rag --model MODEL
slb score results/*/*.jsonl
# the task streams and environments
from datasets import load_dataset

ds = load_dataset("haizhongzheng/ServeLearnBench", "banking_l2")
ds["serving"][0]["instruction"]
